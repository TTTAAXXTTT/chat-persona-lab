# Changelog

## 0.1.0 — 2026-10-19

- First independent public edition, with a fresh repository history.
- Local XLSX and text-export ingestion, SQLite indexing, per-contact examples,
  and aggregate self-message style statistics.
- Human-reviewed drafts, local JSONL inbox/outbox, optional cloud models,
  and experimental Windows desktop adapters.
- Fictional demo generator, onboarding guide, privacy documentation, CI,
  tests, and a curated source-release builder.
- Replaced machine-specific account and recipient locks with explicit local
  configuration while retaining single-recipient and human-confirmation checks.
- Private chat records, profiles, credentials, databases, logs, client installers,
  and previous Git history are excluded from this edition.
