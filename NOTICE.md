# Third-party components

The core Python implementation and local HTML interface are included in this
repository. Python and its standard library are supplied by the user's Python
installation and retain their own licenses.

Optional `wxauto4` and `wxautox4` packages are installed separately and are not
vendored here. Their authors' license terms and any required commercial
authorization apply separately. Installing a package does not provide a paid
service license. WeChat clients and installers are not distributed here.

DeepSeek and OpenCode Go are optional external services. Their API terms,
model availability, pricing, and privacy policies are maintained by their
respective providers. This project is not affiliated with those providers or
with WeChat/Tencent.

All supplied demo conversations and profile rows are fictional and created
specifically for the public edition. No real account or contact is needed to
run the offline demo.
